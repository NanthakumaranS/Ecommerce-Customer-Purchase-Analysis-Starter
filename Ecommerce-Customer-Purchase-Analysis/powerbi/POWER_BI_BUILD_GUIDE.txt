POWER BI BUILD GUIDE
====================

1. Open Power BI Desktop.
2. Get Data > MySQL database.
3. Server: localhost (or your MySQL server); Database: ecommerce_analytics.
4. Select customers, products, orders, order_items, payments.
5. Choose Import for this portfolio project.
6. In Model view, create/check these one-to-many relationships:
   customers[customer_id] 1 -> * orders[customer_id]
   orders[order_id] 1 -> * order_items[order_id]
   products[product_id] 1 -> * order_items[product_id]
   orders[order_id] 1 -> * payments[order_id]
7. Keep filter direction single from dimension/parent table to fact/child table.
8. Create measures from DAX_measures.txt. If Power BI reports ambiguous filter paths for a measure, use a dedicated sales fact query/view in MySQL or create a star schema.
9. Page 1: four Card visuals for Total Revenue, Total Orders, Units Sold, Average Order Value; line chart with order_date by month and Total Revenue; bar chart by category.
10. Page 2: bar chart top products by revenue; matrix with category, product, units, revenue, estimated gross profit.
11. Page 3: table of customer name, order count and revenue; bar chart by city; card for Repeat Purchase Rate.
12. Page 4: donut chart payment method; column chart order status; table with payment status and amount.
13. Add slicers for order_date, category, city, and order_status.
14. Format currency as INR only if you label it clearly; the generated sample values are generic currency units, not actual INR transactions.

CSV IMPORT ORDER
================
Use MySQL Workbench > Schemas > ecommerce_analytics > Tables > right-click each table > Table Data Import Wizard.
Import in this order:
customers.csv, products.csv, orders.csv, order_items.csv, payments.csv.
Map columns by matching names. Ensure dates are interpreted as YYYY-MM-DD.
